## Setup
1. Download the project files.
2. Move the `quick tab switcher` into your `/addons` folder inside your Godot project.
3. **Enable the addon** through the **project settings**, and now you can switch tabs with ease!

## How to use
Press **Ctrl + 1 - 9** to quickly switch tabs in the Godot editor scene. When you press **Ctrl + 9** it brings you to the last tab of the project.
